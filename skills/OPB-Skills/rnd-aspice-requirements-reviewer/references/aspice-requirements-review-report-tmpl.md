# ASPICE 需求评审报告模板

> 本模板用于输出ASPICE需求评审的标准化报告
> 适用于SYS.1/SYS.2/SWE.1各级需求评审
> 版本：1.1
> 更新：增加需求状态过滤说明，仅评审Released状态需求

---

## 模板使用说明

```
[[LLM: 根据评审过程中收集的信息，填充以下各节内容。
- 所有 {{placeholder}} 需要根据实际评审情况替换
- 表格中的示例行需要根据实际发现的问题进行填充
- 如某节内容不适用，标注"N/A"并说明原因
]]
```
